# FoodExp

Tracciatore intelligente di scadenze alimentari. Scansiona i codici a barre, ricevi notifiche prima che il cibo scada e riduci gli sprechi.

## Funzionalità

- **Scansione barcode** — Inquadra il codice a barre e aggiungi automaticamente il prodotto
- **Tracciamento scadenze** — Visualizza a colpo d'occhio cosa scade oggi, domani o tra 3 giorni
- **Notifiche push** — Avvisi automatici prima della scadenza
- **Ricerca** — Trova rapidamente qualsiasi alimento nella tua dispensa
- **Aperto/Chiuso** — Segna i prodotti come aperti per tracciare la shelf-life post-apertura
- **Speech-to-text** — Aggiungi prodotti dettando il nome

## Tech Stack

- **Flutter** (Dart) — Cross-platform iOS e Android
- **SQLite** — Database locale, nessun account richiesto
- **mobile_scanner** — Scansione barcode in tempo reale
- **flutter_local_notifications** — Notifiche di scadenza
- **speech_to_text** — Input vocale

## Getting Started

```bash
flutter pub get
flutter run
```
